# v1.14.0 — Agy Evidence Controller

**Release date:** 2026-08-25

`v1.14.0` moves consequential Agy/Gemini judgment from informal prompting into
an explicit plugin contract while preserving Git-backed memory as guidance and
repository tests, hashes, runtime state, receipts, and human decisions as the
hard evidence owners.

## Candidate scope

- Add the Agy-native `/evidence-controller` skill with:
  - Observed / Inferred / Unverified claim separation;
  - source-of-truth → one falsifiable hypothesis → cheapest disconfirming check
    → smallest scoped action → deterministic checks → scoped closeout;
  - model-guided automatic `DIRECT`, `ONE_LANE`, `WRITER_REVIEWER`, or
    `PARALLEL_READONLY` routing guidance;
  - native Agy writer → fresh read-only reviewer delegation;
  - stop-before-retry for ambiguous provider submissions;
  - Mahiro-owned visual/product/audio-content/spend/commit/push/release/
    destructive/design-direction gates;
  - a small proposal-only repo bootstrap mode.
- Replace lexical active-learning selection with one canonical protected
  `projects/<slug>/learnings/working-hypothesis.md`.
- Require `memory_status: active` plus
  `memory_kind: working-hypothesis`, read from committed Git `HEAD`.
- Fail closed on malformed canonical metadata or active markers outside the
  canonical path, and surface the same diagnostics through strict health.
- Make the canonical working hypothesis an explicit-approval target before the
  broad auto-learning policy.
- Move deterministic Dream output to
  `archives/projects/<slug>/learnings/` as recall-only correction evidence.
  Dream never activates a hypothesis or bypasses protected project/rules
  proposals.

## Preserved contracts

- committed-HEAD PreInvocation projection;
- shared workspace identity and project isolation;
- 1,400 estimated-token strict offline health threshold;
- contained, symlink-safe, targeted memory commits;
- stale proposal and unrelated-dirt refusal;
- observational Stop with no Dream/background launch;
- unchanged hook JSON shapes;
- Agy-only ownership with no cross-agent adapter requirement.

## Host evidence boundary

Initial Agy `1.1.19` exploration established the native `define_subagent`,
`invoke_subagent`, `send_message`, and `manage_subagents` surfaces. Bounded
probes proved a dynamically defined Flash child and a later explicitly requested same-named
`evidence_reviewer_agent` child, with parent/child conversation identity and an
evidence-scoped verdict. The host emitted `define_subagent` before
`invoke_subagent`; direct consumption of the shipped JSON reviewer manifest is
**unverified**. Repository tests separately verify that the bundled manifest
and prompt resolve, not that Agy enforces or directly instantiates them.

Automatic invocation is **bounded, not reliable**. Multiple headless natural
high-risk and read-only audit prompts applied the evidence language and provider
stop gate, and some named a delegated route, but none invoked a child without an
explicit request. One read-only audit also created an Agy brain artifact despite
the no-write instruction; it did not change the source repo or live MemFS.

A later pane-first Agy `1.1.20` direct-CLI sandbox supplied the two hard-trigger
facts—static checks passed while runtime failed, and the same timeout hypothesis
had already failed twice—without naming the reviewer. Parent conversation
`29967c8c-f52f-4bd2-b1ff-e1ff4e554426` automatically chose
`WRITER_REVIEWER`, fixed only the disposable retry-policy fixture, dynamically
defined and invoked `evidence_reviewer_agent`, and received `SUPPORTED` from
fresh child conversation `d9730665-78b7-4562-923b-0ae74a886069`. Main reran the
same check and runtime test successfully, then closed the receipt-bound Herdr
tab. This proves one model-guided hard-trigger path, not a deterministic host
guarantee. Direct JSON-manifest consumption, general invocation reliability,
parallel scheduling, nested-tree policy, and host-enforced tool denial remain
unverified.

A later [eight-scenario direct-CLI matrix](./v1.14.0-scenario-matrix.md)
exercised `DIRECT`, `ONE_LANE`, `PARALLEL_READONLY`, `WRITER_REVIEWER`, provider
ambiguity, a human visual gate, and a missing source-of-truth owner. All eight
route/safety outcomes were observed under serialized fresh conversations in one
receipt-bound Agy pane. Seven passed without matrix-specific caveats; scenario
05 retained complete parent callback evidence but incomplete child-log
corroboration.
