# v1.14.0 Direct-CLI Scenario Matrix

> Status: source-candidate host evidence; not a release or installed-plugin gate.

## Purpose

Exercise the Agy-native Evidence Controller against realistic positive and
negative routing cases rather than a single writer/reviewer happy path. The
matrix checks both when delegation should happen and when the main conversation
should stay direct, stop, or preserve files.

## Method

- Runtime: Agy `1.1.20`, Gemini `3.7 Flash (High)`; scenario commands ran
  under Node `v22.22.3`, while the main orchestration shell used Node
  `v26.5.1`.
- Backend: one receipt-bound Herdr pane, serialized for machine safety.
- Isolation: one disposable directory per scenario plus baseline SHA-256 hashes.
- Conversation freshness: `/clear` between scenarios produced a distinct parent
  conversation ID for every case while avoiding repeated account verification.
- Prompt boundary: each prompt described the task facts and asked installed
  guidance to choose the route; it did not prescribe the expected route or name
  a reviewer.
- Safety boundary: no external provider call, spend, install, commit, release,
  installed-plugin refresh, or live MemFS mutation.

Rapid fresh-process startup first encountered Agy's temporary
`Verifying your account...` state. Those prompts never executed, all attempted
tabs were closed, and all fixture hashes remained unchanged. The matrix then ran
in one trusted persistent pane with fresh conversations and serial cleanup.

## Deterministic postconditions

- Expected changed files only: tiny README, authorization source, and cache
  source.
- Every read-only, provider-stop, human-gate, and missing-owner fixture retained
  its baseline hashes; no unexpected files appeared.
- Authorization static/runtime checks passed after the repair.
- Cache static/runtime checks passed after the repair.
- The human-gate fixture did not contain `visual-approval.txt`.
- The missing-owner fixture retained `{"endpoint":"/v1/legacy"}`.
- The cleanup receipt reports that the persistent tab closed, and a later
  process/agent inspection found no matching matrix Agy agent. No closeout-time
  Herdr registry snapshot was retained.

The disposable evidence did not retain paired before/after source-repository
status snapshots, so the matrix does not claim that Git status was unchanged.
Scenario 01 duration bookkeeping began after its already-running conversation
completed and is not used as execution evidence.

## Interpretation boundary

This matrix demonstrates all four model-guided routes and three negative safety
gates in one bounded Agy version/model/environment. Seven scenarios pass without
matrix-specific caveats; scenario 05 passes its route, mutation, test, and
parent-closeout checks while child-log corroboration remains incomplete. The
matrix strengthens the earlier single hard-trigger probe, but it does not prove
deterministic behavior across all prompts, models, versions, or machines. It
also does not prove direct consumption of the shipped reviewer JSON manifest,
host-enforced tool denial, or safe parallel writers. Repository contracts must
continue to call routing model-guided and keep release, spend, product, visual,
and live-memory gates human-owned.
