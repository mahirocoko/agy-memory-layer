# v1.12.1 — Contract-Safe Git Memory Lifecycle

**Release date:** 2026-08-20

`v1.12.1` replaces broad autonomous-memory claims with executable boundaries
that were verified in fixtures and in a real interactive Antigravity host.

## Highlights

- PreInvocation projects committed Git `HEAD`; uncommitted memory is disclosed
  but never injected.
- Stop is observational and no longer stages, commits, repairs locks, or starts
  Dream work.
- Shared memory writes are contained, symlink-safe, atomic, clean-repository
  guarded, and committed with exact pathspecs.
- `/init` and Letta import use explicit confirmation boundaries. Letta import
  requires an exact agent and scope; project scope also requires a slug.
- Backup restore, installer/update/uninstall ownership, confirmed purge, and
  remote Git sync fail closed on unsafe state.
- Markdown compaction is now read-only analysis. Dream remains deterministic
  Agy note synthesis rather than an overclaimed Letta reflection equivalent.
- Active docs, prompts, skills, reports, and project memory now describe the
  executable current contract.

## Upgrade

The bundled `/update` command refreshes the active current-source links; it does
not download releases. For a local checkout, pull `v1.12.1` and rerun the root
installer or update command. For a cached remote installation, rerun the root
installer first so its source checkout advances.

## Deferred Boundaries

This release does not claim:

- Letta-style isolated model reflection with cursor/reservation/worktree merge;
- release acquisition with atomic switch and rollback;
- self-contained remote runtime dependency packaging;
- host-enforced subagent tool restrictions;
- live external-network or Dream/cron E2E coverage.
