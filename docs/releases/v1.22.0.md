## Boundaries

- The 32,000-token value is a strict offline health gate and runtime notice threshold, not a guarantee that every future host accepts an arbitrary single message.
- Transport chunking is not a per-file content ceiling and does not make `/dream` an automatic consolidator.
- Native subagent tier names such as `flash`, `inherit`, and `pro` do not prove an exact resolved model ID without live host/session evidence.
- Interactive supervision, human product/visual/spend/release gates, and the existing non-parity boundaries remain in force.
