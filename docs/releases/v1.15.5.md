# v1.15.5 — Letta Parity, Active Memory Density & Process Resilience

**Release date:** 2026-09-03

**State:** Released as `v1.15.5`.

`v1.15.5` hardens `agy-memory-layer` runtime performance and behavioral parity with upstream
Letta Code (v0.31.6, commit `28233621`). It resolves the active memory budget
overrun, integrates progressive middle-truncation across retrieval and reflection,
adds background process liveness with orphan detection, enforces strict AST layer
boundaries in CI, and wires subagent isolated worktrees.

## Runtime & Parity Improvements

- **Active Memory Budget Curation**: Reduced injected system memory from ~1,678
  tokens to 1,203 tokens (-28%), eliminating yellow budget warning notices while
  maintaining all core workflow, communication, and persona invariants.
  Historical source units are preserved under `archives/curations/cur-active-memory-budget-consolidation/`.
- **Progressive Middle-Truncation (`middleTruncateText`)**: Preserves 30% head
  (user intent) and 30% tail (outcomes) with dropped-character markers when
  processing large conversation transcripts in `recall-engine.ts` and `dream-daemon.ts`.
- **Process Liveness & Orphan Detection**: Added `process-liveness.ts` with
  `isProcessAlive`, `isCurrentProcessOrphan`, and `startOrphanDetection` to prevent
  zombie background workers and stale locks when terminal sessions disconnect.
- **Stale Lock Recovery**: Added `reclaimStaleMemoryWriteLock` in `memory-write-lock.ts`
  to automatically reclaim dead-PID lock files safely without manual file deletion.
- **AST Layer Boundary Linter**: Added `scripts/check-layer-boundaries.ts` to
  enforce strict TypeScript `type` aliases (no `interface`), lifecycle hook isolation,
  and plugin boundary containment in `pnpm check`.
- **Subagent Worktree Isolation**: Connected `agent-launcher.ts` with
  `worktree-manager.ts` (`prepareSubagentExecution`) to isolate writer subagent actions
  in dedicated Git worktrees.
