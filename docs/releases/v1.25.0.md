# v1.25.0 — Tiered v2 Memory, Bundled MCP Server & Offline Palace

Release version: `v1.25.0`. Publication status is owned by GitHub Releases.

## Scope

- Adds Tiered v2 MemFS layout support (`Core.md`, `index.md`, `*/index.md`, `procedures/`, `system/`, `reference/`, `projects/<slug>/`) with additive lossless `migrate-v2` planning, application, and rollback, while preserving committed-`HEAD` projection and legacy flat fallback.
- Bundles a zero-dependency stdio MCP server (`plugins/agy-memory-layer/mcp_config.json`, `scripts/mcp-server.sh`, `scripts/memory-mcp-server.ts`) exposing `agent_memory_read`, `agent_memory_edit`, `agent_memory_reflect`, `agent_memory_doctor`, `agent_memory_history`, and `agent_memory_palace`.
- Adds an offline, single-file Letta-grammar Memory Palace generator (`scripts/palace-render.ts`) as the default viewer engine in `scripts/palace-server.sh` (with `--legacy` fallback to `palace-generator.ts`), writing `0600` viewer HTML under `~/.gemini/memory.state/viewers/` without injecting memory from dirty working trees.
- Adds deterministic schema validation, retrieval, reflection policy, and context-budget diagnostics across `memory-schema.ts`, `memory-engine.ts`, `memory-retrieval.ts`, `memory-reflect.ts`, and `reflection-policy.ts`.
- Adds 6 memory workflow skills (`context-doctor`, `creating-skills`, `initializing-memory`, `maintaining-core-memory`, `maintaining-deferred-memory`, `syncing-memory-filesystem`) for a total of 20 plugin skills.
- Retains standalone native operation and opt-in `v1.24.0` shared communication protections (`system/human/prefs/communication.md` proposal diversion and source-owner gating). Native Agy works without Letta, and Human/source-owner approval remains required before any shared communication proposal alters canonical upstream sources.

## Usage and boundaries

Generate and open the default offline Memory Palace for the current workspace:

```sh
./plugins/agy-memory-layer/scripts/palace-server.sh --open
# Or fall back to the legacy template generator:
./plugins/agy-memory-layer/scripts/palace-server.sh --legacy --open
```

The bundled stdio MCP server (`agy-memory-layer`) is registered through `plugins/agy-memory-layer/mcp_config.json` and launches automatically when Antigravity CLI loads the plugin. Legacy MemFS layouts remain supported cleanly; additive upgrade to Tiered v2 can be previewed and applied through `memory-mcp-server.ts` / `layered-memory-migration.ts` (`migrate-v2`).

Interactive, human-supervised execution remains required. Native Agy works without Letta, does not enable unattended scheduling or unsupervised execution, treats summaries and recalled notes as non-authoritative historical evidence, and keeps Git commits explicit (`Stop` remains strictly observational). Human/source-owner approval remains required for shared communication proposals, and local Git repositories still send projected session context to the configured model provider during inference.
