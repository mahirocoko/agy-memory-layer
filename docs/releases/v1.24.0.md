# v1.24.0 — Optional Shared Communication

Release version: `v1.24.0`. Publication status is owned by GitHub Releases.

## Scope

- Adds opt-in shared communication from an explicit, distinct local Git repository, reading only committed `system/human/prefs/communication.md` at one pinned revision per view.
- Retains native persona, routing, project memory, recall, and unrelated learning. Native Agy works without Letta; any source satisfying the fixed-owner contract may provide the optional baseline.
- Preserves tested nested lists, labels, paragraph/list introductions, and native additions while explaining unresolved structural differences and source provenance.
- Diverts shared communication updates to private pending proposals. Inspect, export, and reject are available; proposals never automatically rewrite native or canonical source memory.
- Protects direct, buffer, commit, restore, approval, curation, migration, and reflection paths, including atomic mixed batches and caller overrides that cannot weaken runtime policy.
- Marks synthesized search positions as virtual instead of claiming physical native file lines.

## Usage and boundaries

Leave sharing disabled for normal standalone use. To opt in, run:

```sh
node --experimental-strip-types plugins/agy-memory-layer/scripts/shared-memory.ts enable /absolute/path/to/shared-git-repo
node --experimental-strip-types plugins/agy-memory-layer/scripts/shared-memory.ts status
```

The source file must be regular, committed, within the explicit Git root, and satisfy content/size checks. Uncommitted edits are not injected. Context still goes to the selected model provider; local Git is not provider-offline operation.

Only communication is shared. Whole-memory sync, shared chat/task state, arbitrary semantic equivalence, OS-level sandboxing, and unsupervised readiness are not claimed. Human/source-owner approval remains required to apply proposals. Existing conversations may need a fresh chat to load new context.
