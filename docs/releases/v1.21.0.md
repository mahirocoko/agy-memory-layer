# v1.21.0 — Cross-Project Dream Daemon & State Recovery

**Release date:** 2026-09-24

**State:** Released as `v1.21.0` for interactive, human-supervised use.

## Scope

- **Cross-Project Dream Execution**: `dream-daemon.ts` now supports `--all-projects` to scan and reflect on conversations across all workspaces in a single execution.
- **Targeted Project Reflection**: Added `--project <slug>` to allow running reflection on any initialized project from any workspace without directory navigation.
- **Multi-Project Grouped Status**: Added `--status --all-projects` to report pending and uninitialized conversation counts partitioned by project.
- **Safe Uninitialized Project Handling**: Conversations belonging to workspaces without initialized project memory (`projects/<slug>/` in MemFS) are intentionally skipped from writing and their progress cursor (`lastDreamedSteps`) is preserved, ensuring lessons remain eligible for reflection once `/init` is performed.
- **Two-Phase Transaction & Single-Lock Acquisition**: Reads transcripts and builds candidate notes without locking, acquires the global MemFS write lock once, verifies clean repository state, commits per-project archives independently, and saves atomic cursor state.
- **Resilient & Atomic State Persistence**: `saveDreamState` now writes via atomic temporary file rename (`.tmp-*` -> rename), handles corrupted JSON gracefully with automatic fallback, and archives corrupted state files to `.corrupt-<timestamp>`.
- **Exported Project Scope Validation**: `workspace-identity.ts` now exports `projectScopeExists` for clean consumer boundary verification.
