## Usage and boundaries

Refresh the plugin links and preview/apply Tiered v2 migration safely:

```sh
./plugins/agy-memory-layer/scripts/update.sh
node --experimental-strip-types plugins/agy-memory-layer/scripts/memory-engine.ts migrate-v2 --dry-run
node --experimental-strip-types plugins/agy-memory-layer/scripts/memory-engine.ts migrate-v2
node --experimental-strip-types plugins/agy-memory-layer/scripts/memory-engine.ts doctor
pnpm memory:health -- --workspace "$(pwd)"
bash plugins/agy-memory-layer/scripts/palace-server.sh --open
```

Interactive, human-supervised execution remains required. Native Agy works without Letta, does not enable unattended scheduling or unsupervised execution, treats summaries and recalled notes as non-authoritative historical evidence, and keeps Git commits explicit (`Stop` remains strictly observational). Human/source-owner approval remains required for shared communication proposals, and local Git repositories still send projected session context to the configured model provider during inference.
