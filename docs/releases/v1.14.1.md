# v1.14.1 — Installed Hook Symlink Runtime

**Release date:** 2026-08-25

`v1.14.1` is a runtime patch for the Agy Evidence Controller release. It fixes
PreInvocation and Stop hooks invoked through the installed plugin symlink and
makes lifecycle validation exercise that real path instead of accepting empty
output.

## Defect

`v1.14.0` passed source-path, disposable lifecycle, schema, and live MemFS
checks. The first post-release installed-path probe then found both hook output
files empty even though each process exited successfully.

Node resolved `import.meta.url` to the source realpath while `process.argv[1]`
retained the symlink path. The old direct-execution guard compared those values
without canonicalization, so the CLI handler never attached stdin listeners.
Install/update validation redirected output to `/dev/null` and checked only the
process exit, allowing the empty success through.

## Fix

- Add one shared realpath-aware `isDirectCliInvocation` helper.
- Use it for PreInvocation, Stop, memory-repository, and memory-health CLI
  entrypoints.
- Invoke hook validation through the installed symlink in root install, plugin
  install, and update flows.
- Parse and assert the exact `injectSteps` and `decision: stop` JSON contracts;
  empty output now fails the lifecycle command.
- Extend the disposable lifecycle regression to invoke both hooks through the
  installed symlink and require non-empty schema-valid output.

The verification runtime was Agy `1.1.20`, Node `v26.5.1`, and pnpm `10.33.0`.
No real provider submission, paid side effect, or additional live content
migration was used for this patch. The `v1.14.0` MemFS migration remained clean
at `5a7d2c7`; after release, only the explicit `learn-letta-code` version context
is updated to name `v1.14.1`.

## Upgrade

For a local checkout, pull `v1.14.1` and run:

```bash
./plugins/agy-memory-layer/scripts/update.sh
```

For a cached one-line installation, rerun the root installer so its source
checkout advances before invoking `/update`.
