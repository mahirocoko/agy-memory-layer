# v1.13.0 — Scoped Active Memory Health

**Release date:** 2026-08-24

`v1.13.0` repairs the active Agy memory projection and the live Git MemFS so
project scope, prompt size, Dream synthesis, and recovery evidence remain
bounded and testable without deleting historical knowledge.

## Highlights

- Initializer, PreInvocation, Dream, and the health auditor share one workspace
  identity resolver. Existing explicit child scopes are preserved, while
  ordinary monorepo paths resolve to their Git-root project by default.
- PreInvocation reads committed Git `HEAD`, injects at most one learning marked
  `memory_status: active`, and never activates archive paths or uncurated legacy
  Dream notes.
- A strict offline health command verifies repository cleanliness, complete
  project scopes, a 1,400-token projection threshold, archive exclusion, and
  transient-file hygiene. Runtime PreInvocation remains advisory above the
  threshold rather than truncating rules or suppressing hook calls.
- Deterministic Dream maps local Agy conversation history to project scope,
  fails closed when ownership is unknown, normalizes retention markers, and
  writes only actionable explicit durable rules or facts. Vague and no-signal
  sessions advance external skipped-state without creating boilerplate memory.
- Backup export now includes every tracked regular file regardless of filename
  extension, with regression coverage for tracked transient-looking evidence.
- Active docs, skills, tests, package metadata, and Memory Palace branding now
  describe the same `1.13.0` runtime contract.

## Live MemFS Repair

- The pre-repair repository was captured as a verified Git bundle and a
  checksum-verified `agy-memfs-bundle/v1` export.
- An exact 73-operation migration manifest passed dry-run and disposable-clone
  simulation before live application.
- Historical Dream material was moved to recall-only archives rather than
  deleted; source conversation history was not rewritten.
- All six active workspace projections fell from 2,307–3,653 estimated tokens
  to 629–689, below the 1,400-token strict health threshold.
- The live MemFS finished clean at commit `71b62fc`.

## Upgrade

The bundled `/update` command refreshes active links from the current source; it
does not acquire releases. For a local checkout, pull `v1.13.0` and rerun the
root installer or update command. For a cached remote installation, rerun the
root installer first so its source checkout advances.

## Deferred Boundaries

This release does not claim:

- Letta-style isolated model reflection with cursor/reservation/worktree merge;
- a host persistence contract that permits suppressing repeated PreInvocation;
- runtime truncation as a substitute for the strict offline health threshold;
- release acquisition with atomic switch and rollback;
- self-contained remote runtime dependency packaging;
- host-enforced subagent tool restrictions.
