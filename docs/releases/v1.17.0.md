# v1.17.0 — Compiled Contract Ledger & Autonomous Governance Skills

**Release date:** 2026-09-03

**State:** Released as `v1.17.0`.

`v1.17.0` introduces a dedicated architectural governance framework to `agy-memory-layer`, solving rule entropy, context bloat, and documentation drift across active repositories. It implements a compiled intermediate contract ledger (`contract-ledger.ts`) and two complementary slash command skills (`/contract-refine` and `/contract-align`) that operate as a closed-loop pair programming control system.

## Core Improvements & Additions

- **Compiled Contract Ledger (`scripts/contract-ledger.ts`)**:
  - **Shared Deterministic Core**: Compiles repository `AGENTS.md` (Hub) and `docs/**` (Spokes) into a structured, hash-stamped intermediate contract artifact (`ContractLedger`), eliminating context token bloat from repeated raw Markdown re-parsing.
  - **Deterministic Verification (`verify`)**:
    - Validates that all relative Markdown links in documentation resolve to existing files.
    - Flags machine-specific absolute paths (`/Users/...`, `file:///...`) for environment-agnostic hygiene.
    - Verifies active Hub-and-Spoke reachability (ensuring all non-historical docs are discoverable from `AGENTS.md`).
    - Excludes historical documentation and version releases from active rule deduplication.
  - **Code Evaluation (`eval`)**:
    - Scans source code against active `current-reality` contract rules.
    - Supports recursive directory traversal (`collectCodeFiles`) across `.ts`, `.tsx`, `.js`, `.jsx`.
    - Supports `--ledger <path>` to enforce verification against a frozen contract artifact.
    - Implements **Prose Overruling Code Protection**: Evaluates a **Strict Majority Threshold (> 50%)**; if the majority of scanned files violate a rule, it is classified as a *Contract Finding* (indicating the rule is aspirational `preferred-direction`) and routed back to docs maintenance, rather than generating dozens of conflicting code diffs.

- **Twin Governance Skills (`skills/`)**:
  - **`/contract-refine`**:
    - Refactors repository rules and documentation.
    - Enforces **Lossless Curation** (`keep | merge-into | move-to | historical | duplicate | rejected`) with unit-based diffs.
    - Prevents unreviewable full-file overwrites via strict human review gates.
  - **`/contract-align`**:
    - Enforces active project contracts against source code.
    - Runs AST and deterministic checks first (strict `type` aliases, comment tags, centralized constants) before heuristic review.
    - Produces surgical, review-first diffs without auto-committing.

- **Hardening from Cursor Fable 5.1 Review**:
  - **Unicode Normalization**: Updated rule ID computation to `\p{L}\p{N}` Unicode properties, ensuring multilingual (Thai/English) rules produce stable, distinct SHA-256 identifiers without collisions.
  - **Strict Majority Calculation**: Corrected boundary comparison to `violatingFilesCount * 2 > totalScanned` (strict > 50%).
  - **Link Parsing Robustness**: Added fenced code block exclusion and link title stripping.
  - **Status Sentinel Matching**: Restricted status parsing to explicit sentinel tokens (`[preferred-direction]`).
