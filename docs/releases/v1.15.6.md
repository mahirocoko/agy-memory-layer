# v1.15.6 — Subagent Trio, Pure Conductor Pattern & Dual Fable Parity

**Release date:** 2026-09-03

**State:** Released as `v1.15.6`.

`v1.15.6` brings full declarative subagent orchestration and independent falsification
reviews to `agy-memory-layer`. It introduces the Subagent Trio (`repo_scout_agent`,
`bounded_writer_agent`, `evidence_reviewer_agent`), documents the Pure Conductor
pattern to prevent author bias, and hardens subagent prompt contracts through an
independent peer review by Claude Fable 5.1 via `direct-cli`.

## Core Improvements & Parity Additions

- **Subagent Trio (`repo_scout_agent`, `bounded_writer_agent`, `evidence_reviewer_agent`)**:
  - `repo_scout_agent`: Fast, read-only flash-tier explorer that maps codebase reality and target anchors.
  - `bounded_writer_agent`: Scoped implementation worker with strict 2-strike repair budget, dependency installation prohibition (report to Main), and all state-altering Git commands forbidden.
  - `evidence_reviewer_agent`: Upgraded to "claims bounded, search unbounded" whole-repo read-only inspection to catch cross-cutting regressions and callers without tunnel vision.
- **Pure Conductor Pattern**:
  - Decouples Main Agent from writing code on complex or risky tasks to eliminate author confirmation blindness.
  - Formally documented in `system/human/prefs/workflow.md` and `reference/human/workflow-nuances.md`.
- **Evidence Controller Wiring**:
  - Connected `repo_scout_agent` as the default `ONE_LANE` scout and `bounded_writer_agent` + `evidence_reviewer_agent` as the default `WRITER_REVIEWER` pair in `skills/evidence-controller/SKILL.md`.
- **Dual Fable Peer Review (`direct-cli`)**:
  - Evaluated and remediated through two independent audit rounds with Claude Fable 5.1 (`claude-fable-5-1-high`) via `direct-cli` in Herdr.
  - Remediated reviewer scope contradiction, writer Git safety, dependency safety, and contract test assertions (Round 2 Verdict: PASS).
