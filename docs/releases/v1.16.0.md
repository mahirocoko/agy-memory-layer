# v1.16.0 — Host-Enforced PreToolUse Guardrails & Lifecycle Safety Gates

**Release date:** 2026-09-03

**State:** Released as `v1.16.0`.

`v1.16.0` elevates `agy-memory-layer` from prompt-guided policy to host-enforced deterministic guardrails via the official Antigravity IDE Hooks specification. It introduces a dedicated `PreToolUse` hook with an escalate-only classifier that intercepts tool execution before process dispatch to protect Git history, enforce package installation gates, contain filesystem writes, and prevent subagent capability escalation.

## Core Improvements & Parity Additions

- **Host-Enforced `PreToolUse` Guardrails (`tool-guard.ts` & `hook-pre-tool-use.ts`)**:
  - **Escalate-Only Posture**: Never grants permissions or widens authority; returns `ask` as neutral baseline and escalates strictly to `force_ask` (human gate popup) or `deny` (hard block). Fallbacks fail closed to human review (`ask`/`force_ask`).
  - **Git Safety Gate (`run_command`)**:
    - Destructive Git operations (`reset --hard`, `clean -fd`, `push --force`, `checkout -- .`, `restore .`, `branch -D`, `filter-branch`, `reflog expire`) are intercepted and **denied** to prevent unrecoverable data loss.
    - State-altering Git operations (`commit`, `push`, `checkout`, `switch`, `restore`, `reset`, `stash`, `rebase`, `merge`, `tag`) are escalated to **`force_ask`** to guarantee explicit user authorization.
    - Quoted POSIX word splitting and wrapper stripping (`env`, `sudo`, `command`, `xargs`, `VAR=val`) prevent command laundering.
    - Opaque inline interpreters (`sh -c`, `bash -c`, `eval`, `node -e`, backticks, subshells `$()`) trigger mandatory human review (`force_ask`).
  - **Dependency Installation Gate**:
    - Intercepts package manager additions (`pnpm add`, `npm i <pkg>`, `yarn add`, `bun add`, `cargo add`, `go get`, `brew install`) and escalates to **`force_ask`** per AGENTS.md rule 5.
    - Permits bare lockfile restoration (`pnpm install`, `npm install`).
  - **Filesystem & MemFS Containment (`write_to_file` & `replace_file_content`)**:
    - Intercepts direct writes to `~/.gemini/memory/` and returns **`deny`** (memory must be committed via the approval writer).
    - Intercepts direct writes to `.git/` metadata and returns **`deny`**.
    - Intercepts sneaky manifest tampering (`package.json`, lockfiles) via write tools and escalates to **`force_ask`**.
  - **Subagent Capability Boundary (`define_subagent`)**:
    - Enforces read-only manifests (`repo_scout_agent`, `evidence_reviewer_agent`, `recall_agent`, `history_analyzer_agent`); attempts to grant write tools or nested subagents return **`deny`**.
- **Lifecycle Hook Expansion**:
  - `hooks.json` now registers **3 lifecycle hooks**: `PreInvocation` (context injection), `PreToolUse` (tool guard), and `Stop` (observational repository status).
- **MemFS Budget Micro-Compaction**:
  - Compacted `projects/learn-letta-code/system/overview.md` and `system/human/prefs/coding.md` down to 1,365 tokens, strictly within the 1,400 token ceiling.
