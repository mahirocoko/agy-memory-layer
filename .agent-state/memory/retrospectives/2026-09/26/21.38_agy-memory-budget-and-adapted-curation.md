## What Could Improve

1. Build the cross-runtime adaptation ledger before preparing the first proposal, not after a byte-copy target has already been proven mechanically. This would reduce repeated plan hashes and disposable proofs.
2. Completion waits should use a receipt or exact terminal marker rather than a narrow lifecycle-state filter. Herdr's `done` state appeared before the final visible response, so status alone created a false failure narrative.
3. Snapshot every generated-but-pre-existing file immediately before a command known to rewrite it. The second full-suite run overwrote `TEST_REPORT.md`; recovery succeeded only because the earlier exact backup still existed.

- **Runtime mismatch**: byte-for-byte Letta copy contained stale routes. Resolved through a focused Agy runtime owner and live catalog/manifest evidence.
- **Semantic adaptation gaps**: verifier found three dropped portable constraints. Restored them, regenerated the ledger/plan, and obtained a clean narrow re-verification.

## Honest Feedback

The session was more iterative than it needed to be. First, I treated byte preservation as the main correctness target before fully separating portable human preference from runtime-specific execution policy. That produced a proposal that was safe to reject but still cost several proof cycles. Second, I trusted Herdr lifecycle status too readily and announced a native-child hang before checking the final terminal/transcript evidence; the correction was fast, but the first report was wrong. Third, I ran the full suite without taking a fresh backup of the already modified generated report, relying on a prior backup to restore the user's bytes. None of these caused lasting damage because the curation protocol, Git history, exact hashes, and independent verifier caught them, but the process should become more front-loaded: ownership map first, semantic ledger second, one disposable proof third, human approval last. The final result is stronger because the verifier was allowed to block rather than being treated as ceremonial reassurance.

## Lessons Learned

- A complete source-to-target ledger is necessary but insufficient; adapted units need semantic counterexamples, not only target-prefix existence.
- Model presence in `agy models` does not by itself prove a native child resolved to that exact model ID.
- Lifecycle `idle` / `done` is coordination metadata, not terminal-report proof.
- Curation must refuse pre-existing Git index locks before writing any target.
- Generated evidence files that were dirty before the session need exact byte backups before rerunning generators.
