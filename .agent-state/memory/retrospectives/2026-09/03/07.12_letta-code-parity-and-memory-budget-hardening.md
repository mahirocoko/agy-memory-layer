Collaborating on this session was exceptionally rewarding. What started as an upstream codebase exploration evolved into concrete, high-leverage architectural hardening for `agy-memory-layer`. When Mahiro asked about Letta's memory token usage, breaking down the differences between Letta's Core Memory blocks (2,000 char hard cap) and MemFS on-demand tree indexing revealed the exact reason for our 1,678-token budget warning. Rather than discarding our always-active in-context injection, we used our own `memory-curation.ts` engine to densify our preferences into concise, high-signal English. Dropping from 1,678 to 1,203 tokens instantly resolved the yellow prompt warning while leaving nearly 200 tokens of buffer. Adopting Letta's progressive middle-truncation and orphan detection patterns further solidifies our runtime resilience.

## Honest Feedback (3 Friction Points)
1. **Initial Memory Budget Creep**: Rules in `system/human/prefs/` had grown organically without density checks, allowing verbose phrasing to push total injected tokens above the 1,400 threshold.
2. **Lossless Curation Safeguard Strictness**: Direct memory proposal via `memory-approval.ts` correctly rejected paraphrasing of durable units, requiring us to construct a full `MemoryCurationSpec` with explicit summary dispositions. While strict, this guard prevented accidental knowledge loss.
3. **Biome Formatting Strictness on String Concatenation**: Biome flagged string concatenation in tests preferring template literals (`HEAD_START_${...}`), which required a quick format fix before `pnpm check` could exit 0.

---

## Lessons Learned
- **Memory Density is an Invariant**: System prompt memory must be concise, high-signal English. Detailed rationales belong in `reference/` under Progressive Disclosure.
- **Middle-Truncation Preserves Both Intent and Outcome**: Blindly slicing transcripts from index 0 drops the final execution results; middle-truncation (30% head + 30% tail + marker) is the mathematically optimal compromise for context budgeting.
- **Static Boundary Linters Eliminate Regressions Early**: Adding `check-layer-boundaries.ts` to `pnpm check` guarantees that TypeScript `type` conventions and layer import boundaries remain uncompromised across future iterations.
