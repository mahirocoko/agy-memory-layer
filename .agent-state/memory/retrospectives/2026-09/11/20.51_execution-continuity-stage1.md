## Session Summary

The session completed the execution-continuity experiment through its authorized Stage 1 boundary.
Stage 0 replaced an invalid monolithic prototype with nine deterministic scenarios over disposable
Git and state roots. Stage 1 then produced 15 distinct retained Agy session receipts across Modes
A, B, and C for C1–C5. Raw scoring initially said both candidate modes passed 5/5, but Main's direct
state audit disproved that result: Mode B retained stale preflight fingerprints in four cases, and
Mode C closed terminal states while leaving agent-owned criteria open in every case. Both candidates
were disqualified, Stage 2 was not started, and no runtime supervisor was built. The scorer, tests,
documentation family, and current project memory were hardened around the observed defects.

Before this retrospective, local pulse data counted 35 prior retrospectives across seven active
days, zero earlier retrospectives today, and 16 modified/untracked paths on `main`. Those values are
derived snapshots, not canonical telemetry; this retrospective was not yet included in them.

## Architecture Decisions

- A scored agent experiment is not valid when the grader accepts a terminal state without checking
  the persisted criterion evidence and candidate fingerprint that state claims to summarize.
- Candidate fingerprints must have a predeclared algorithm and artifact path set. A helper inside
  each disposable fixture now makes that contract executable rather than implied.
- A Letta-led controller must copy and reread exact child/result criteria before closing a mission;
  setting only the top-level terminal state is internally contradictory.
- Transient Herdr `done` observations are insufficient. Collection requires a stable terminal streak
  plus the expected result artifact.
- Stage 1 failure is a useful result. Neither candidate may advance merely because the harness was
  repaired after the calls; new source cannot retroactively turn historical receipts into PASS.

- รักษาเพดาน 15 scored Agy sessions และไม่เริ่ม Stage 2 หลังทั้งสอง candidate ล้มเหลว
- แยก model behavior, raw scorer, Main audit และ independent verification ออกจากกัน
- หยุดและแก้ completion gate เมื่อ Herdr รายงาน `done` ชั่วคราวระหว่าง Agy ยังทำงาน
- ปิดทุก pane, ลบ disposable roots/temporary receipts และไม่ทิ้ง process residue
- ปรับ current documentation family พร้อม deterministic regressions แทนการเก็บบทเรียนไว้แค่ใน
  สรุปสนทนา
- Final checks ผ่าน 73/73 tests, 11/11 integration scenarios, aggregate coverage 83.55% lines,
  71.00% branches, 87.63% functions, `pnpm check`, context drift audit, strict Gitleaks, and CCC
  refresh.

## What Could Improve

1. Freeze original runner source, initial mission snapshot, dispatch receipts, and canonical timing
   receipt before every scored call—not only their hashes and final state.
2. Predeclare criterion IDs and fingerprint format in executable form before Mode A, avoiding two
   scorer-only grammar caveats and the later B-C4 representation ambiguity.
3. Treat terminal mission consistency as a first-class assertion from the beginning: top-level
   state, owned criteria, evidence, fingerprint, and parent audit must move atomically.
4. Use a tiny two-cell canary after material harness changes before spending the rest of a matrix.

## Lessons Learned

- Raw PASS เป็นเพียง claim จนกว่าจะเทียบกับ persisted owner state และ exact artifact identity
- Harness repair หลังการทดลองไม่แก้ historical result; ต้องบันทึก no-advance แล้วขอรอบใหม่
- Evidence reproducibility ต้องออกแบบก่อน execution ไม่ใช่สังเคราะห์ย้อนหลัง
- Stable terminal status ต้องประกอบด้วย lifecycle settlement และ expected artifact
- Project docs now own these lessons, so no duplicate non-canonical learning note is promoted by
  this RRR.
