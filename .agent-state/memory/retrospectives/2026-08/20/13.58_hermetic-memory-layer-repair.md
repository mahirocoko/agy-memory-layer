## Lessons Learned

- A test orchestrator must fail the process when any captured scenario fails; a green outer runner is otherwise meaningless.
- Hermetic tests need unique HOME, MemFS, temp root, worktree source, and checkout-name independence—not merely an `AGY_MEMORY_DIR` override.
- Security validation must finish before dry-run, target cleaning, existence checks, or writes; dry-run is not permission to probe escaped paths.
- Independent verification is most useful when asked to disprove exact claims and allowed to change the checkout name or inject a controlled failure.
- User-owned external state is a hard boundary even when repository instructions list it as a version surface.
