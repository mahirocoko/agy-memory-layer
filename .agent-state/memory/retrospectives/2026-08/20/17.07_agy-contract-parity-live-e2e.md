## Honest Feedback

มี friction หลักสามจุด หนึ่ง ผมรายงาน completion ก่อนทำ live AGY E2E ทั้งที่คำว่า parity และ lifecycle plugin มี host behavior เป็นส่วนสำคัญ นี่เป็น scope miss ที่ควรป้องกันด้วย DoD ไม่ใช่แก้ด้วยคำชี้แจงปลายทาง สอง verifier loop ใช้เวลาหลายรอบเพราะ contract บางข้อเขียนกว้างกว่าพฤติกรรมจริง เช่น “exact scope” แต่ global route ยังเขียน project paths อยู่ ถ้าผมสร้าง write-set matrix และ inverse tests ก่อน จะปิดช่องนี้ได้เร็วกว่า สาม direct-cli selector รายงาน Herdr failure แบบรวม ๆ ทำให้ตอนแรกดูเหมือน skill ไม่ตรวจ Herdr ทั้งที่สาเหตุจริงคือ client `0.8.2` protocol 20 กับ server `0.8.0` protocol 19 ไม่ compatible รอบต่อไปควรเปิด explicit preflight detail ทันทีเมื่อ auto fallback เพื่อไม่ให้คนอ่านเข้าใจว่าเลือก tmux แบบเดาสุ่ม อย่างไรก็ตาม การ cleanup ทำได้ดี: memory test data ถูกคืนหรือลบผ่าน scoped writer, Git จบ clean และไม่มี pane/temp fixture ค้าง

## Lessons Learned

- Host plugin release ต้องมี real interactive smoke นอกเหนือจาก schema/unit/integration tests
- Scope flag ต้องกำหนด write set จริง และต้องมี inverse test ยืนยันว่าไม่เขียนข้าม scope
- Lifecycle ownership preflight ต้องเกิดก่อน mutation แรกและครอบคลุม registration ทุกตำแหน่ง
- Temporary real-user-state tests ต้อง snapshot, commit แบบ targeted, restart พิสูจน์ persistence แล้ว cleanup คืน exact bytes
- Auto backend fallback ควรรายงานเหตุผล compatibility ที่ละเอียดพอให้วินิจฉัยได้ทันที
